# אפליקציית שעון מעורר לשבת ולימי חול (iOS 17)

אפליקציית שעון מעורר מותאמת אישית לאייפון (iOS 17), הפועלת ועוצרת **עצמאית לחלוטין ללא מגע יד** (כיבוי אוטומטי מוגדר מראש, למשל לאחר 2 דקות), ומיועדת הן לשבת קודש והן לכל ימות השבוע.

---

## תכונות מרכזיות

* ⏱️ **כיבוי אוטומטי מותאם אישית (Auto-Silencing)**:
  השעון מצלצל למשך הזמן שבחרת (למשל: 30 שניות, 1 דקה, **2 דקות**, 3 דקות, 5 דקות או 10 דקות), ונכבה מעצמו. אין שום צורך לגעת במכשיר, להחליק או ללחוץ על כפתורים.
* 🕯️ **מצב מעמד שבת (OLED Nightstand Mode)**:
  מסך שחור מוחלט (True Black OLED) לחיסכון בסוללה ומניעת אור בחדר השינה, שעון דיגיטלי עמום מאוד, מניעת כיבוי מסך (`isIdleTimerDisabled`), והשמעה חלקה ללא רטט.
* 📅 **גמישות מלאה לכל השבוע**:
  הגדרת שעונים לשבת בלבד, לימי חול (ראשון–חמישי), לכל יום, או בחירת ימים מדויקת.
* 🔊 **השמעה אמינה ברקע ועקיפת מתג ההשתקה**:
  מוגדר באמצעות `AVAudioSession` בקטגוריית `.playback` ו-`UIBackgroundModes: audio` להשמעה יציבה.
* 🎵 **הגברה הדרגתית (Fade-In)**:
  עלייה עדינה בווליום במשך 10–20 שניות למניעת בהלה מתוך שינה.
* 🛑 **אפס רטט בשבת**:
  הרטט מבוטל כדי למנוע טלטול של מוקצה והפרעה של מכשיר רועד על השידה.

## איך להפיק את קובץ ה-IPA ולהתקין באייפון

מכיוון שאתה עובד על מחשב Windows ויש צורך בסביבת macOS לקומפילציה, הפרויקט כולל תסריט **GitHub Actions** מובנה (`.github/workflows/build-ipa.yml`), המאפשר לך לקבל את קובץ ה-`.ipa` מוכן להורדה תוך 2 דקות:

### שלב 1: העלאת הקוד ל-GitHub (ריפו חינמי)
1. פתח חשבון ב-[GitHub](https://github.com) (אם אין לך עדיין).
2. צור מאגר חדש (New Repository) – ניתן להגדיר אותו כ-**Private** (פרטי).
3. פתח PowerShell בתיקיית הפרויקט:
   ```powershell
   cd "C:\Users\Orel lugasi\.gemini\antigravity\scratch\ShabbatAlarmApp"
   git init
   git add .
   git commit -m "Initial commit for Shabbat Alarm App"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
   git push -u origin main
   ```

### שלב 2: הורדת קובץ ה-IPA מ-GitHub Actions
1. בדף המאגר ב-GitHub, עבור ללשונית **Actions**.
2. תראה את התהליך **"Build Shabbat Alarm IPA"** רץ אוטומטית על שרת Mac של GitHub.
3. כעבור כ-2–3 דקות, התהליך יסתיים בהצלחה (וי ירוק).
4. לחץ עליו, ובתחתית המסך תחת **Artifacts** תמצא את הקובץ:
   👉 **`ShabbatAlarm-iOS17-IPA`** (קובץ `.ipa` מוכן להורדה!).

### שלב 3: התקנה על האייפון עם רישיון מפתח (Sideloadly / AltStore)
1. הורד ופתח את **[Sideloadly](https://sideloadly.io/)** (או תוכנת ההתקנה שבה אתה משתמש ב-Windows).
2. חבר את האייפון שלך למחשב בכבל USB (או דרך Wi-Fi אם מוגדר).
3. גרור את קובץ ה-`ShabbatAlarm.ipa` שהורדת לתוך Sideloadly.
4. הזן את ה-Apple ID שלך (המשויך לרישיון המפתח שלך).
5. לחץ על **Start** – תוך שניות בודדות האפליקציה תותקן על האייפון שלך ב-iOS 17!

## הנחיות מומלצות לשימוש בשבת
1. **חיבור למטען**: מומלץ להשאיר את המכשיר מחובר למטען על השידה לפני כניסת השבת.
2. **הפעלת מצב שבת**: בכניסה לחדר השינה לפני השינה, פתח את האפליקציה ולחץ על **"מצב שבת"**. המסך יישאר עמום וכהה ולא ייכבה.
3. **מצב פוקוס / נא לא להפריע**: הפעל "נא לא להפריע" כדי למנוע שיחות או הודעות שיאירו את המסך במהלך השבת.
4. **אפס מגע**: בשעה היעודה, השעון יצלצל למשך 2 דקות (או הזמן שהגדרת) ויפסיק מעצמו ללא שום פעולה מצדך. שבת שלום ומבורך!
